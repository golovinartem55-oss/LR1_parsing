## Что сделано

**Шаг 1–1.1.** Окружение, параметры варианта 10, учебный динамический стенд.

**Шаг 1.2.** Локальный HTTP-сервер со стендом (`market_stand.html`). Доказано: в исходном HTML — **0 строк данных**, всё рисует JavaScript.

**Шаг 2.** Запуск headless Chromium 156.0 через Playwright. Контекст с `--no-sandbox`, `--disable-dev-shm-usage`, блокировка тяжёлых ресурсов.

**Шаги 3–5.** Сбор данных с динамического стенда:
- cookie-баннер закрыт каскадом XPath (1 оверлей);
- гидратация: первая порция — 12 строк;
- догрузка через кнопку «Показать ещё» — **2 клика**;
- **итог: 30 строк** собрано, распарсено через `lxml`;
- явные ожидания (`wait_for_function`) вместо `time.sleep`.

**Шаг 6.** Очистка признаков и выгрузка:
- суффиксы K/M/B → числа (`parse_suffix_number`);
- проценты с Unicode-минусом → доли единицы (`parse_percent`);
- деньги с валютой → числа (`parse_money`);
- даты `дд.мм.гггг` → `Timestamp` (`parse_date_ru`);
- **100 % распознано** объёма и капитализации, 97 % изменения за 24 ч;
- пропуски (`n/a`, `—`) сохранены как `NaN`, а не заменены нулями;
- Excel с двумя листами (`data`, `by_sector`), закреплённой шапкой и числовыми форматами.

**Шаг 7.** Бизнес-анализ и визуализация:
1. Топ-10 по обороту с выделением лидера (`Prisma`, 3460.0 млн).
2. Распределение изменения за 24 ч (медиана +7.07 %, растут 20, падают 9).
3. Когорты лидеров роста и падения (по 5 позиций).
4. Капитализация против оборота (log-log).

## Как воспроизвести

1. Открыть ноутбук в Google Colab или локальном Jupyter.
2. Убедиться, что в шаге 1 стоит `VARIANT = 10`.
3. `Среда выполнения → Выполнить все`.
4. Дождаться прохождения всех ячеек (первая ячейка может занять 30–60 секунд при первой установке Chromium).
5. Артефакты появятся в рабочей папке:
   - `market_stand.html` — учебный стенд;
   - `lr1_variant10_startups.xlsx` — Excel с очищенными данными;
   - `page.png` — скриншот целевой страницы;
   - `lr1_plots.png` — четыре графика.

## Ограничения

- **Данные учебные.** Стенд использует детерминированный генератор с seed, зависящим от номера варианта. Числа воспроизводимы, но не являются рыночной реальностью.
- **Разовый срез.** Данные отражают состояние стенда на момент запуска.
- **Реальная площадка** для варианта 10 — Dealroom (региональные дашборды). Легальные альтернативы для продакшена: OpenAlex, Росстат, ЕГРЮЛ. Сбор с реальных площадок требует учёта `robots.txt` и пользовательского соглашения.
